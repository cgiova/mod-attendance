Approccio semplice (architetturale) — moltiplicatore α


dopo aver ottenuto gli embedding x1 (immagini) e x2 (tabulari), moltiplichiamo x2 per un coefficiente scalare α.

Così se α = 0 → il modello ignora i tabulari,
se α = 1 → uso bilanciato,
se α > 1 → tabulari amplificati.

--------------------------------------------
alpha = tf.constant(0.5, dtype=tf.float32)  # scegliere alpha, qui 0.5

# Definire input layers
image_input = keras.Input(shape=(*CFG.image_size, 3), name="images")
feat_input = keras.Input(shape=(feature_space.get_encoded_features().shape[1],), name="features")
inp = {"images": image_input, "features": feat_input}

# Branch per immagine
backbone = keras_cv.models.EfficientNetV2Backbone.from_preset(CFG.preset)
x1 = backbone(image_input)
x1 = keras.layers.GlobalAveragePooling2D()(x1)
x1 = keras.layers.Dropout(0.2)(x1)

# Branch per tabular
x2 = keras.layers.Dense(96, activation="selu")(feat_input)
x2 = keras.layers.Dense(128, activation="selu")(x2)
x2 = keras.layers.Dropout(0.1)(x2)

# Applica il peso alpha solo alla modalità tabellare
x2_weighted = keras.layers.Lambda(lambda x: x * alpha, name="tabular_weighting")(x2)

# Concatenazione
concat = keras.layers.Concatenate(name="concat")([x1, x2_weighted])

# Output layer
out = keras.layers.Dense(1, activation="sigmoid", dtype="float32")(concat)

# Build model
model = keras.models.Model(inp, out)

model.compile(
    optimizer=keras.optimizers.Adam(learning_rate=1e-4),
    loss=keras.losses.BinaryCrossentropy(label_smoothing=0.02),
    metrics=[keras.metrics.AUC()],
)

model.summary()

Approccio più raffinato — regolarizzazione nella loss

Qui non modifichiamo l’architettura, ma aggiungiamo un termine di penalità alla loss che riduce la dipendenza dal ramo tabulare (o immagine).
Misuriamo la “dipendenza” tramite la norma L2 dei pesi che connettono la modalità alla testa finale.

--------------------------------------------

lambda_reg = 1e-4  # intensità del termine di regolarizzazione da scegliere

# Recuperiamo il layer denso finale e il layer Concatenate
dense_final = model.layers[-1]
concat_layer = [l for l in model.layers if isinstance(l, keras.layers.Concatenate)][0]

# Troviamo l'indice di separazione fra x1 e x2 nella concatenazione, serve a sapere quanti pesi appartengono alla parte tabellare
dim_img = concat_layer.input[0].shape[-1]
dim_tab = concat_layer.input[1].shape[-1]

# Definizione di loss custom
def weighted_loss(y_true, y_pred):
    # BCE base
    base_loss = keras.losses.binary_crossentropy(y_true, y_pred, label_smoothing=0.02)

    # Penalità sui pesi che connettono la parte tabellare all’output
    W = dense_final.kernel  # matrice [dim_img + dim_tab, 1]
    W_tab = W[dim_img:]     # seleziona solo la parte tabellare
    reg_term = lambda_reg * tf.reduce_sum(tf.square(W_tab))

    return base_loss + reg_term

# Ricompila il modello con la nuova loss
model.compile(
    optimizer=keras.optimizers.Adam(learning_rate=1e-4),
    loss=weighted_loss,
    metrics=[keras.metrics.AUC()],
)

Commenti:

A livello teorico la seconda modalità è la migliore perchè interviene direttamente sull'ottimizzazione, ma è meno interpretabile. La prima modalità è più diretta ma non interferisce bene col training, lo costringe in maniera brutale con un peso fissato, mentre inserire la penalizzazione nella loss è un modo più gentile.
